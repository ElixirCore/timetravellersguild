3.3 V logic only

COIN is open-collector: it pulls to ground and never sources voltage. Pull up to 3.3 V, never to 12 V. Power the mech alone first and measure COIN to GND; some clones carry their own pull-up. Clamp with a diode if it reads above 3.3 V.

  1. Mechanism. Switch to NO, speed slow. Teach £1 as one pulse with real coins.
  2. Audio. microSD formatted FAT32. Tracks named 0001.mp3 upward: Jack's recorded lines.
  3. Playback. Count the pulse burst, then play one track while BUSY is low. Coins that land mid-line are counted but don't start a new line.
  4. Before power. Rail polarity and continuity. COIN voltage as in the warning. Speaker reads about 8 Ω. Nothing mains-voltage inside the box.
