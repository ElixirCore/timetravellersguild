How much of the prompt is voice?

Every turn the model is handed identity.txt first (9,310 characters). Hover a slice.

The voice instruction is one sentence: "Be warm, curious, candid and conversational. You do not need to sound like a customer-service assistant." That is 104 of 9,310 characters, about 1%. The honesty rule that follows it is longer and stricter, and the rest is room, coding lab and Arnold manuals. Also: "Respond to simple conversation simply." A second file, identity-v2.txt (939 characters, voice and honesty only), sits beside it; the code reads only identity.txt.

Levers, if the aim is a more interesting Quill

  1. Give the voice more room in identity.txt: what a good reply looks like, permission to have opinions, ask back, follow a tangent. Positive instructions, not only constraints.
  2. Let the truth gate judge claims about the world, not every assertive sentence in plain chat.
  3. Turn the stock refusals into an instruction to the model, so a refusal is still a sentence Quill would say.
  4. Drop "Be concise" from the receipt rewrite on conversational turns.
  5. Put a budget on the prompt so the voice is not buried by a long history.

Directions only. Nothing in the code has been touched.

Caveats

This is read from code, not from a traced conversation. Which spot fires on a given dull reply stays a hypothesis until one such turn is followed through the logs.

Line numbers are from the 10 Oct package. The 12-stage pipeline, the Groq call and the truth gate are all still present after the refactor; the new part is a per-turn record (turn_context.py) holding provenance, permitted tools, receipts and one retry allowance per stage.
